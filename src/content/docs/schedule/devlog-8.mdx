    [My Project - Typed](https://gettyped.vercel.app/)

    The core interaction flow and visual identity have already been established. The current focus is improving the quality and specificity of the AI-generated personality results while refining the overall user experience and interactivity.


1. What functionality proves your concept is feasible?

    My proof of concept shows that Typed can collect user entertainment preferences, process those choices, and generate a personality-style result from the collected data. The most important functionality is the connection between user interaction, stored preference signals, and the final AI-generated personality output.

1. Share a visual describing your prototype

    <img src="/dig345-devlog/results.png"></img>

1. Describe “separation of concerns” using your project as an example

    For Typed, separation of concerns means keeping each part of the app focused on a specific task. The interface handles the visuals and interaction flow, local storage manages user choices, APIs provide entertainment data, and the AI system generates the personality results. Separating these systems keeps the project organized and prevents unnecessary complexity.

1. What did you struggle with while building the prototype?

    The hardest part was making the AI-generated results feel personal instead of repetitive or generic. I also struggled with balancing the amount of interaction so the experience felt meaningful without becoming too long.

1. Most helpful website, tutorial, or resource

    The most useful resources were the Next.js documentation, Spotify API documentation, TMDB API documentation, and OpenAI API examples.

1. What is the 1st most important feature you will implement next?

    Improve the AI result generation system so personality outputs feel more specific and personalized.

1. What is the 2nd most important feature you will implement next?

    Add polished shareable result cards that users can save or post online.

1. What is the 3rd most important feature you will implement next?

    Add friend comparison or compatibility features between different Typed results.
